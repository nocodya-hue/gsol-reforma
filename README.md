# G·SOL Reformas Integrales (web de muestra)

Propuesta de web y logo para **G·SOL Reformas Integrales**, empresa de reformas integrales y rehabilitación de casas antiguas en Valencia (tel. 657 34 48 01).

**Web online:** https://nocodya-hue.github.io/gsol-reforma/

- **Logo** redibujado a partir del suyo: «G·SOL» con el punto convertido en sol y un tejado dorado encima.
- **Hero:** el nombre gigante detrás de una alquería rehabilitada.
- **Paneles** de servicios, antes y después y plano de la reforma animado.
- **Opiniones** reales de Google.
- Web estática, sin cookies ni analítica.

**Imágenes:** todas son **ilustrativas, generadas con IA**, porque la empresa aún no tiene fotos propias publicadas.

**Pendiente de confirmar con el cliente:** WhatsApp del móvil, razón social y NIF para el aviso legal, la dirección y el dominio.
